# 웹드라이브 접속 설정 안내 (윈도우)

사무실 밖에서도 회사 웹드라이브를 윈도우에서 사용하기 위한 설정입니다.
순서대로 따라 하시면 됩니다. 10분 정도 걸립니다.

**로그인 계정은 평소 쓰시던 비서(biseo) 계정 그대로입니다.** 새로 만드실 것 없습니다.

---

## 1단계 — NetBird 설치

회사 내부망에 안전하게 연결해주는 프로그램입니다.

1. 아래 주소에서 설치 파일을 받습니다
   ```
   https://pkgs.netbird.io/windows/x64
   ```
2. 받은 파일을 실행해서 설치합니다
3. 설치가 끝나면 화면 오른쪽 아래 시계 옆에 NetBird 아이콘이 생깁니다

---

## 2단계 — 서버 주소 설정 (⚠️ 가장 중요)

**이 단계를 빠뜨리면 로그인은 되는데 아무것도 안 보입니다.**

1. 시계 옆 NetBird 아이콘을 **오른쪽 클릭** → `Settings`
2. `Management URL` 칸에 아래 주소를 정확히 입력합니다
   ```
   https://net.biseo.kr
   ```
3. 저장합니다

---

## 3단계 — 로그인

1. NetBird 아이콘을 클릭하고 `Connect`를 누릅니다
2. 인터넷 브라우저가 자동으로 열립니다
3. **Keycloak**을 선택합니다
4. **평소 쓰시던 비서 계정**으로 로그인합니다

---

## 4단계 — 관리자 승인 기다리기

로그인하면 아래와 같은 화면이 나올 수 있습니다.

```
User Approval Pending
Your account is pending approval from an administrator.
```

**정상입니다. 잘못된 것이 아닙니다.**

보안을 위해 관리자가 한 명씩 확인 후 승인하도록 되어 있습니다.
담당자에게 승인을 요청하시고, 승인되면 NetBird에서 다시 `Connect`를 눌러주세요.

시계 옆 아이콘이 연결됨 상태로 바뀌면 준비가 끝난 것입니다.

---

## 5단계 — 연결 확인

시작 메뉴에서 `cmd`를 검색해 명령 프롬프트를 열고 아래를 입력합니다.

```
ping 10.10.2.233
```

응답이 오면 정상입니다. 응답이 없으면 아래 **문제가 생겼을 때**를 봐주세요.

---

## 6단계 — 웹드라이브 연결

윈도우 탐색기는 이 방식(SFTP)을 지원하지 않아서 별도 프로그램이 필요합니다.
**WinSCP**를 권장합니다. (https://winscp.net — 무료)

설치 후 아래와 같이 입력합니다.

| 항목 | 입력값 |
|---|---|
| 프로토콜 | **SFTP** |
| 호스트 이름 | `10.10.2.233` |
| **포트 번호** | **`38592`** |
| 사용자 이름 | 비서 계정 아이디(또는 이메일) |
| 비밀번호 | 비서 계정 비밀번호 |

> **포트 번호를 꼭 `38592`로 바꿔주세요.** 기본값(22)인 채로 두면 연결되지 않습니다.

연결되면 회사 드라이브의 파일이 보입니다.

---

## 매일 사용하실 때

- 컴퓨터를 켜면 NetBird가 자동으로 연결됩니다
- 시계 옆 아이콘이 **연결됨** 상태인지만 확인하시면 됩니다
- 연결이 안 되어 있으면 아이콘을 클릭해 `Connect`를 누르세요
- 회사 안에서든 밖에서든 동일하게 사용하실 수 있습니다

---

## 문제가 생겼을 때

### 연결은 됐는데 드라이브가 안 보여요

명령 프롬프트에서:

```
netbird status
```

`Networks:` 옆에 `10.10.2.0/24`가 보여야 합니다. `-`로 되어 있으면
**담당자에게 "NetBird 그룹 배정이 안 된 것 같다"고 알려주세요.**

### 아이디/비밀번호가 맞는데 드라이브 로그인이 안 돼요

이 기능은 **내부 사무 담당자 전용**이라, 일부 소속만 사용할 수 있도록 되어 있습니다.
담당자에게 문의해 주세요.

### 그 외

아래 세 가지를 순서대로 시도해 보세요.

1. NetBird에서 `Disconnect` 후 다시 `Connect`
2. 컴퓨터 재시작
3. 그래도 안 되면 담당자에게 아래 정보와 함께 문의

```
명령 프롬프트에서 실행한 결과를 복사해서 전달
  netbird status
  ping 10.10.2.233
```

## 참고 — 인터넷이 느려지지 않나요?

**느려지지 않습니다.**

이 프로그램은 **회사 내부 주소로 가는 통신만** 처리합니다.
네이버, 유튜브 등 일반 인터넷 사용은 평소와 똑같이 동작합니다.
